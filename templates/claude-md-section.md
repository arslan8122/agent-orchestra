## Architecture decisions
- Accepted decisions live in `docs/adr/` (see `docs/adr/README.md`). Read the index before changing architecture.
- Never contradict an Accepted ADR. If one is wrong, draft a superseding ADR with `/adr supersede NNNN`.
- When a change makes a design choice a future engineer would ask "why?" about, draft a Proposed ADR on the same branch.
- Never edit an Accepted ADR's Decision or Consequences; supersede it instead.
